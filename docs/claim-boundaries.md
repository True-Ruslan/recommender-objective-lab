# Claim boundaries for an article

Use formulations like:

- "In this synthetic model, the engagement-first objective leads to ..."
- "The experiment demonstrates a possible mechanism under stated assumptions."
- "Clicks and user value need not be identical targets."
- "In the ablation, removing fatigue substantially reduces the gap."
- "Production research increasingly treats long-term satisfaction/retention as a separate objective."

Avoid formulations like:

- "Engagement algorithms make people addicted."
- "We proved that social networks manipulate users."
- "CTR is useless."
- "YouTube/TikTok behave like this simulation."
- "Our satisfaction metric is the correct definition of user welfare."
- "Preference drift in the model proves that recommenders rewrite human preferences."

The most defensible central claim is:

> If a measurable proxy is not identical to the desired long-term outcome,
> optimizing the proxy can select a different policy from optimizing the broader
> outcome. The resulting trade-off is an objective-design problem, not merely a
> prediction-quality problem.
